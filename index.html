Folder Test

Checks whether Agora could use a folder on this phone. It only writes inside a folder named “Agora test”, and never changes or deletes your own files.

Checking…

1Pick your My Files folder

Create a folder called “My Files” in your phone’s Files app first and put a few files in it. Then tap below, open that folder and tap “Use this folder”, then “Allow”.

2Speed test (read only)

Pick a big folder, such as Pictures › Screenshots. The test counts every file and opens one picture. Nothing is changed.

3Close and reopen

Swipe this app away from your recent apps so it closes completely, then open it again from its icon. The box at the top will say whether it still has the folder. Try once more tomorrow too.

4Send the results

Copies everything this test found, so you can paste it into the chat with Claude.
